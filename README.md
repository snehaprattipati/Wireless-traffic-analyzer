# Wireless Traffic Analyzer

A network traffic capture and analysis project using tcpdump and Wireshark on Linux.

## What it does
- Captures live network traffic using tcpdump on Linux
- Analyzes TCP and UDP packet behavior in Wireshark
- Identifies real-world protocols on live WiFi networks

## Tools Used
- tcpdump (Linux)
- Wireshark (Windows)
- iPerf3 (traffic generation)

## Analysis Performed

### 1. Live WiFi Network Capture
- Captured real traffic from live WiFi network
- Identified protocols: ARP, QUIC, SSDP, IGMPv3, TCP
- Analyzed real device communication on local network

### 2. TCP Traffic Analysis
- Captured TCP packets generated by iPerf3
- Identified TCP 3-way handshake (SYN, SYN-ACK, ACK)
- Observed ACK packets and retransmissions

### 3. UDP Traffic Analysis
- Captured UDP packets generated by iPerf3
- Compared UDP vs TCP packet structure
- Observed UDP has no handshake and larger packet sizes

## Key Learnings
- TCP uses 3-way handshake, ACKs, and retransmissions for reliability
- UDP skips handshake and sends large chunks directly for speed
- Real networks carry many protocols simultaneously
- Wireshark filters help isolate specific protocol traffic
